CropMind Core Engine

Developer API Portal

Browser requests that change data must send the header X-Requested-With: CropMind. Complete documentation for the CropMind backend services. Connect to authentication, manage crop datasets, log IoT sensor telemetry, and interface with Google's Gemini AI.

Authentication Endpoints
POST /api/auth/register Register a new farmer account
AuthenticationNone Required
Rate Limitlimited per network and per account
Request Payload (JSON)
{
  "email": "farmer@cropmind.com",
  "password": "securepassword123"
}
POST /api/auth/login Authenticate credentials and generate token
AuthenticationNone Required
Rate Limitlimited per network and per account
Response Body (JSON) — the session is set as an httpOnly cookie
{
  "message": "Login successful.",
  "user": {
"id": "603d2e9c15b...",
"email": "farmer@cropmind.com"
  }
}
GET /api/auth/google Initiate Google OAuth flow
AuthenticationOAuth Redirect
DescriptionRedirects the user to Google Login. Automatically falls back to Developer Sandbox OAuth consent screen if client credentials are not defined.
GET /api/auth/me Current logged-in user
AuthenticationSession cookie or Bearer token
POST /api/auth/logout Revoke all sessions and clear the cookie
AuthenticationNone Required
